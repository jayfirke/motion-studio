## Visual style
Single-hue world: violet-to-lavender gradients split diagonally, white UI with a deep-violet sidebar and charts, thin white line art for metaphors, letter-spaced light type for the few kinetic words. The UI is the only texture.

## How the product UI is shown (the demo grammar)
- Real captured UI, tilted in 3D (roughly 15–25°) with a soft shadow; never flat-on.
- The camera explains: a hard push into the code cell (0:27) makes code readable; lateral glides along tables (0:30–0:43) feel like a dolly over a desk.
- Gen-AI as prompt then answer object (table, then code panel) sliding in (0:46–0:49).
- An isometric pull-back over many report tiles (0:56) ends the demo on breadth.
- One key number pulled out large inside the UI (19 %, 0:53).

## Motion and transitions
Long continuous camera moves with only diagonal gradient wipes as transitions. A single white line carries the opening, drawing badge to badge and swooping into the demo. Fast-in, soft-out moves; the camera lands before the VO names the feature.

## Pacing
Moderate VO (115 words/min) but dense music and SFX (152 events per minute, loud), so it feels faster than it talks. Each UI state holds about 3 s while the camera keeps moving. The 18 s intro before any UI is the weak spot.

## Sound
Driving electronic track, tempo read as ~185 (probably a ~92 BPM groove counted double), mastered loud. Smooth male corporate read with feature lists. Tight SFX: ticks on each word swap, whooshes on every glide and wipe; the music carries more energy than the voice.

## What to take from it
- 0:24–0:27: tilt the real UI, then push hard into one cell until the code reads full frame; the camera is the callout.
- 0:30–0:43: lateral glides along tilted real tables keep a static UI alive without cuts.
- 0:46–0:49: prompt, then answer object sliding in (table, then dark code panel); maps straight onto a Claude Code exchange.
- 0:53: pull the one key number out big inside the real dashboard.

## Avoid
- 18 s of line-art metaphors (maze, speedometer, tools badge) before the product.
- Five-spoke benefit diagram after the demo (1:09).
- Master at -12.6 LUFS, 1.4 dB hotter than our -14 target.
