## How the product UI is shown (the demo grammar)
- The narration is typed into a prompt box at the start (0:02.5, 0:16.5): the film behaves like the product, so the viewer reads the voice as if an AI was asked.
- A prompt box with a Start Building button and a cursor is the one real interaction (0:31.9). The filled prompt is then shown (0:36.8).
- Builder screenshots in a green frame, with a cursor on a panel (0:41.7), and a code editor (1:16).
- A four-step chain of icons for the product pipeline: Idea, App, Refine, Deploy (0:46.6).
- Features not shown as UI get a single icon and a label (OCR 0:56.4, AR 1:11, security 1:25.8).

## Motion and transitions
The key trick is a thin green bar or pill that morphs into the next container: the typing field becomes a screen (30.9 s cut frame), a bar widens into a builder window (38.5 s), another bar becomes the next block (47.2 s). Other changes use a mask: a big blob or circle opens onto the next scene (78.8 s iris with the code editor, 94 s cream blob). Easing is smooth with a small settle; type comes in per word with a soft fade.

## What to take from it
- The voice line typed into a prompt box first, so the viewer sees "ask, then it builds" as the film's own grammar (0:02.5, 0:16.5).
- The prompt, then a Start Building button under the cursor, then the result (0:31.9–0:41.7).
- A thin bar that expands into the next container as the carry (30.9 s, 38.5 s).
- A chain of four labelled icons for the pipeline, Idea, App, Refine, Deploy (0:46.6).
- A bold key word in the accent colour in every line (0:36.8, 0:41.7).

## Avoid
- The mountain made of repeated text lines (0:12.3): decoration.
- The AR hand-and-chair stock graphic (1:11) with a glow.
- Full-bleed green with white blobs for the last third (1:20–1:40): a gradient-like ground and a slide-deck feel.
- Words that fade in one by one on the type lines.
