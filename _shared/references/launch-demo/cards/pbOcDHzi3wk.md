# New! Product Launch Video for Best Version Media (SaaS Demo)

- **Link:** https://www.youtube.com/watch?v=pbOcDHzi3wk · **Channel:** What a Story - The Video Partner for SaaS & AI · **Length:** 0:50
- **Type:** launch / demo · **Product:** Best Version Media's advertiser portal, where local businesses see print and digital ad results, sync listings and manage reviews
- **Numbers:** 9.6 transitions per min · median shot 6.2 s (longest 10.7 s) · 118 words/min · ~92 BPM · 145.0 sound events/min · −14.9 LUFS

## Structure (beats with times)
- 0:00–0:05 Hook: a tilted browser window on a teal-navy gradient shows a published ad with magazine covers and a 10.2K+ stat. It slides left for a mixed-weight uppercase headline.
- 0:05–0:09 Entry: a new window rises from the bottom (cut 5.0 s) with the login page. The cursor clicks Login.
- 0:09–0:16 Snapshot: digital-ads rings (18K), the dashboard, then the cursor on Publication Ads opens a full magazine cover (0:16).
- 0:18–0:23 Digital campaigns: a real-time headline, then a performance bar chart scaling up to fill the window.
- 0:24–0:29 Listings: a business card. A Quick Actions panel slides out right, and the cursor clicks "Update Hours", which turns blue.
- 0:30–0:33 Sync: a table of Google, Bing, Yelp, Apple Maps, Foursquare and Meta fills with green checks.
- 0:34–0:40 Reviews: the cursor clicks Discover Reviews, then a benefits checklist and a Contact Publisher button.
- 0:41–0:44 Close: the tagline types on in uppercase on dark, with Ads, Listings and Reviews chips floating.
- 0:45–0:50 Logo: BVM letters assemble block by block, then hold about 3 s.

## Visual style
- Real UI in light mode on a deep teal-to-navy gradient. The white windows glow by contrast, not by effect.
- Windows have a thick white bezel, rounded corners, a slight tilt and a long soft shadow, like floating tablets.
- Uppercase letter-spaced headlines in bold plus light, always beside the window, never over it. The product's own blue for buttons and bars, green only for checks.

## How the product UI is shown (the demo grammar)
- Real screens throughout: login, dashboard, ad rings, chart, listings, sync table, reviews.
- **A vertical window stack:** each new screen rises from the bottom edge as the last one leaves the top (cut frames at 5.0, 16.0, 22.2, 32.8 s).
- A small black cursor clicks one button per beat (0:07, 0:28, 0:37). The button changes colour, then a panel or state follows.
- **Side-panel slide-outs** (0:26) add depth without cutting away.
- **Status fills:** sync checks appear row by row (0:30 → 0:32).
- **Content zoom:** the magazine cover fills the window (0:16) to make a stat concrete.

## Motion and transitions
- Every transition is a vertical push, so the film reads as one long scroll through the product.
- Windows slide sideways to make room for headlines (0:03, 0:18). Subtle tilt changes give a gentle 2.5D feel.
- Smooth, quick easing with no overshoot. Calm and corporate, with no dead time.

## Pacing
- Brisk: about 118 words/min and a new screen every 4–6 s, packing six features into 40 s.
- One action per beat, named by the voice as the window lands. Breaths only at the tagline and the logo.

## Sound
- A mellow bed at about 92 BPM. −14.9 LUFS, on target.
- A friendly, plain narrator with one benefit per sentence and no jokes.
- SFX can't be confirmed; light UI ticks are likely.

## What to take from it
- **A vertical window stack** (5.0, 16.0, 22.2, 32.8 s). Simple carry that feels like scrolling the product.
- **One action per beat with a visible state change** (0:07, 0:28, 0:37). "Cursor presses, UI reacts".
- **Sequential status fills as proof** (0:30–0:32). A table that completes itself.
- **Light UI on a deep gradient, headline beside the window** (0:03, 0:18). Two text levels that read on a phone.

## Avoid
- A login screen as a feature beat (0:05–0:09). Start inside the product.
- Thick bezels and the same tilt on every window. Template feel by 40 s.
- Small uppercase letter-spaced text (0:20). Borderline at 360 px.

## Ideas for the motion-studio launch film
- **Build and critique:** the critique score table fills row by row with green checks as round 3 finishes. Each check gets a soft real click, stepping down in volume.
- **Previs tour → hand-off:** the vertical stack. The previs page exits the top as `approved-video-spec.json` rises from below, then the engine project follows, one upward scroll through the pipeline.
