## What to take from it
- 0:11–0:14: cursor drags a real file into a drop zone that lights up; a setup step shown as a physical action.
- 0:19–0:22: modal changes state in place (Invite → Invitation Sent) while the background blurs.
- 0:23–0:24: KPI numbers counting up the moment the dashboard lands.
- 0:29–0:32: cards lift off the page into depth, a carry from the dashboard into the analytics beat.
- 0:57: the end card's CTA button gets a real cursor click.

## Avoid
- Floating feature chips with heavy blur around the headline (0:04): busy and decorative.
- Logo mark swirling in with motion blur (0:55): reads as a spin.
- 105 words/min and slow eases: too relaxed for the owner's "dense narration" note.

## Ideas for the motion-studio launch film
- Setup chapter: cursor drags the project brief file into the terminal or previs drop zone, the zone lights, and the page reacts.
- Hand-off chapter: an "Approve" button in the previs page, clicked, flips in place to "Approved" with a check while the page blurs, then the spec card lifts off the page and flies to the engine.
- Results chapter: critique scores count up from 0 to 8+ as the report lands.
