- 0:02–0:12 Problem as questions: the admin blurs and real panels float forward one per question (Nexus map 0:07, Product Tax Codes 0:11), each with a round merchant portrait and a teal tag repeating the question; pagination dots count the questions.

## Visual style
Real product UI on a deep teal-to-cyan gradient with soft light blooms; white windows, soft shadows, depth-of-field on background windows. One sans family, kinetic phrases in a light weight. Burned-in subtitles in a dark pill on every shot.

## How the product UI is shown (the demo grammar)
- Real captured UI (Shopify admin, Gmail, Avalara support, Sidekick), with browser chrome and tabs kept so "switching tools" is literal (0:14).
- Arrow cursor with visible clicks on tabs and buttons; × on tab chips doubles as a graphic (0:37).
- Chat as the demo engine: prompt bubble top-right, three-dot loader, dense answer scrolls in; one question per cut.
- Windows tilt back in 3D when text needs room (0:33), then square up for reading.
- A status card pops forward over a blurred window with a static green check (1:03).

## Motion and transitions
Straight cuts on the voice between UI states, plus continuity moves: push into the laptop, dim to teal, windows sliding in from the right. Smooth ease-out, no bounce. The teal stage is the carrier, so cuts never feel like a new world.

## Pacing
Dense: 137 words/min, a new state every 4 s (shortest shot 0.13 s). The problem is shown through action in 24 s. Five questions in 25 s of demo. Rests only on the kinetic line (0:33) and the end card.

## Sound
Bright electronic bed near 129 BPM at -17.6 LUFS. Calm, crisp male narrator; each feature line starts with a verb ("Get…", "See…", "Confirm…"). About 115 sound events per minute: clicks and soft whooshes on cuts and panel moves, steady music with no big drop.

## What to take from it
- 0:13–0:20: show the pain with real browser tabs and a cursor hopping between them.
- 0:39–1:04: one question per shot in the real chat UI (prompt, loader, real answer), five features in 25 s; literally a demo.
- 0:33–0:37: tilt the UI back so a large kinetic phrase shares the frame, then close tab chips with ×.
- 0:24: problem-to-product turn as the whole screen dimming into the brand stage.
- Feature lines as imperative verbs that match what the cursor does.

## Avoid
- Burned-in subtitle pill plus kinetic type breaks the two-text-levels rule.
- Abstract What/Why diagram and Automation ⇄ Compliance loop (1:05–1:30) slow the film after its best section.
- Stock-style smiling merchant (1:21).
