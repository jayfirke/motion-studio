## Structure (beats with times)
- **Hook (0:00–0:08):** a blue kinetic "Everywhere" inside a cloud of floating icon tiles. The tiles collapse into a blue sphere on a pedestal (0:06).
- **Problem (0:08–0:19):** a floating code editor (0:10), then a seesaw with "Code" piled with sheets against "Final Product" (0:15).
- **Turn (0:19–0:24):** the shapes shrink into a "- • <" glyph row that becomes an AI chip badge under the category line (0:23). A blue paper-plane cursor flies in.
- **Who and inputs (0:24–0:47):** "Enterprises" branches to "New Software" and "Legacy" nodes (0:27–0:31). The cursor tours an orbit of Documents / Data / Systems (0:36). A grid of input tiles follows: ticket, PRD, codebase, UX (0:44).

- **Governance (1:04–1:20):** a vertical pill roll with the sharp pill centred and the next one blurred (1:05). Pull back to a tiny "Build" card (1:09) that opens into a pipeline: Spec → Plan → Build → QA → Deploy → the intelligence layer → a model list (Claude, Azure OpenAI, Gemini) (1:13–1:17).
- **Proof (1:20–1:32):** stacked dashboard windows with the cursor gliding over them (1:22). A vertical stat carousel follows (80 %, 16×, 60 %), each stat sharpening as it centres (1:26–1:30).
- **CTA (1:32–1:40):** a blue disc wipe (1:30), the lockup with its tagline (1:34), partner logos (1:38).

## Visual style
Near-white, UI-centric 2D with an ice-blue edge vignette and one accent blue. Light sans headlines (about 5 % height) sit top-centre over the UI. Rounded white tiles with soft shadows and glows. An agency watermark sits top-left throughout.

## How the product UI is shown (the demo grammar)
- Real or close-to-real UI (prompt, agent panels, Kanban, graph, dashboard) as frameless floating windows.
- **Headline over window:** claim first, UI second.
- **Branded cursor:** a blue paper plane that flies in on a curve and lands rather than clicking.
- Windows stack in depth (1:22).
- No typing and no visible press response: the UI arrives already filled in.

## Motion and transitions
- **Almost no cuts:** one 85.5 s camera move. Every element morphs from the last (tiles → sphere → glyph → badge, node → node, pull-back → pipeline).
- **Vertical focus-pull carousels** for pills and stats.
- One disc wipe is the only real break (1:30). Smooth ease-in-out, nothing bounces.

## Pacing
120 wpm over a busy bed, with a state change every 3–4 s and no cuts. But the abstract opener takes 47 s before any product UI appears, and then four UI views rush past in 17 s.

## Sound
The transcript marks music under every line, a steady electronic bed at ~152 BPM (likely 76 half-time). The VO is a calm corporate read in short claims ("What took months now ships in weeks"). The stills can't confirm the SFX. The mix is quiet at -20.9 LUFS.

## What to take from it
- **One-take camera** (0:00–1:25): the clearest carry-not-replace example in the batch.
- **Headline-over-window** (0:56, 1:01).
- **Pull-back reveal** (1:09–1:13): a single card turns out to be one step of a pipeline.
- **Vertical focus-pull stat carousel** (1:26–1:30).
- **Model list as one pipeline stage** (1:17): any model, without a logo wall.

## Avoid
- 47 s of metaphors before the product: the exact slowness the owner criticised.
- Seesaws, icon clouds and glowing spheres.
- A corner watermark.
- UI with no visible cause (no typing, no press).
- An on-screen typo ("Trial" for "Trail").

## Ideas for the motion-studio launch film
