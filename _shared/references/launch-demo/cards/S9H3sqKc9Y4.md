## Visual style
Strict two-colour system: white ground, one corporate blue, red only for problems. Line-art illustration for the story, flat wireframe-clean UI for the demo. Condensed uppercase sans for chapter titles, small light sans for checklists. The UI window sits left of centre at about 55 % width; the right third holds the checklist.

## How the product UI is shown (the demo grammar)
- Redrawn, simplified UI (real layout, placeholder data), flat, no device frame, no tilt.
- Arrow cursor drives everything: it walks a stepper, clicks Accept, hovers rows. Clicks read through the UI change, not a ripple.
- Modals: the page dims about 50 % and a white dialog pops in the centre (signature at 0:54, feedback at 1:35): a clean "focus" device.
- Checklist on the right ticks one item per UI state, so the viewer always knows which feature is on screen.
- One switch to mobile: two phone screens drop in side by side (1:41).

## Motion and transitions
Almost no cuts: one window persists across a whole module and its contents swap in place; between modules only the title block and checklist change. The opening line art draws on and wipes away. Easing is calm and linear-ish; nothing overshoots.

## Pacing
Slow. Each module holds 7–20 s; the window never changes size or angle in 85 s; about one new UI state every 6 s. This is exactly the "slow, not a demo" feeling the owner disliked, despite real UI being present.

## Sound

## What to take from it
- 0:54 and 1:35: dim the page and pop a modal in the centre for the one action that matters; the cursor then clicks the primary button.
- 0:49–2:13: a checklist on the side that ticks as each feature appears, a cheap way to give a dense tour a sense of progress (keep it small; one line at a time).
- Chapter header pattern (icon + module name + playful subline), a consistent signpost across a long tour.
- 1:02: an org chart that grows from one box, a structure built on screen instead of shown finished.

## Avoid
- The static, centred, same-size window for 85 s: no camera, no zoom, no depth. This is the core reason it feels like a slide deck.
- Problem icons in red around a laptop (0:16): stock explainer grammar.
- Watermark logo in the corner on every frame (a corner label, banned).
- Waving line-art hand (0:36): filler.

## Ideas for the motion-studio launch film
