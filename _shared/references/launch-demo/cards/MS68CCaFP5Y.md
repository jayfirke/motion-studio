## Visual style
Mostly flat 2D vector UI on saturated single-colour fields (violet, magenta, sky blue, yellow), white UI cards with soft shadows, geometric sans. Each film owns one brand colour. Glorify adds glossy 3D props; Yotpo uses heavy condensed kinetic type; Descript mixes live footage.

## How the product UI is shown (the demo grammar)
- Redrawn, simplified UI (greyed placeholder bars, a few real labels), never full screenshots.
- Floating browser windows and cards, often tilted 15–30° in 3D with depth blur (2:36–2:42).
- Arrow cursor glides to a target, clicks, and the UI answers: "Open Notes" pill under the cursor (0:36); "Hot Lead" dropdown opens into a coloured status stack (0:52).
- Circular mask zooms into a message card (0:46) as a callout instead of a box highlight.
- Typing: message templates fill a chat field (0:40); Descript shows a blinking caret over real text (8:35).
- Annotation lines snap from the product photo to labels (3:00).

## Motion and transitions
Very few hard cuts inside a film: Leadjet's second half and all of Viable run 80 s with no detected cut. Shots carry by camera pushes into a card, whip-blurred slides of a panel (2:37), circular reveals, and a giant shape wipe (8:11). Easing is snappy ease-out with short settles; bursts of 0.1–0.2 s cuts sit only in Yotpo's montage (6:40, 8:00).

## Pacing
Dense: 150 words/min, a new UI state roughly every 2–3 s, one feature per VO sentence. Breath only at title chips and end cards (about 1 s). Holds on a full screen rarely pass 3 s.

## Sound
Mid-tempo beds (~118 BPM average), a new track per film; -17.8 LUFS overall. Every film is narrated at about 150 words/min (voice timbre not checked: the study reads numbers and captions, not the audio). Script pattern repeats across all seven: pain → "that's why we built" or "introducing" → feature list, one per sentence → CTA. About one sound event per second (59.5/min), so SFX stay sparse under the voice.

## What to take from it
- 0:36–0:52: cursor presses a pill, then a dropdown spills its options; cause then effect every time.
- 0:46: circular mask callout that pushes into one card instead of drawing a box around it.
- 2:36–2:42: tilted 3D panels sliding past with motion blur so a static UI feels like a camera move.
- 1:05–2:10: a whole film with no hard cut, each section carried by a push or morph.
- Script rhythm: one sentence = one visible UI action, at about 150 words/min.

## Avoid
- Flat vector illustration with a magnifier (5:48) and an avatar network with lines (4:12): dated explainer stock.
- Glorify's spinning 3D confetti props (2:12): breaks the no-spin, no-confetti rule.
- Numbered lower-third chips with corner labels.
- Simplified fake UI: we have real product UI and must use it.
