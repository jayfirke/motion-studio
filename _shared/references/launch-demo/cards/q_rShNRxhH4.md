## Visual style
Light lavender ground with thick soft purple "track" lines snaking behind the UI like rails. Odore purple as the one accent; the client's red shows only inside its own screens. Type: a clean sans in near-black, two sizes, with keywords set in white on purple marker chips. UI is real product capture (web dashboard and mobile web) on white cards with soft shadows; phones are frameless rounded screens.

## How the product UI is shown (the demo grammar)
- Real UI throughout: discovery table, filter panel, profile card, analytics, mobile onboarding, rewards.
- Black arrow cursor clicks the Apply button in the filter panel (0:22); the panel then collapses and the next card slides in.
- Typing is shown in the captions, not in fields: each line types out with a purple caret, and a marker chip snaps behind the keyword after the word lands (0:10–0:13).
- Captions build cumulatively: chips stack one under the other while the UI beside them changes (0:31–0:34).
- Mobile flows fan out as 2–3 screens in a row, the middle one larger and forward (0:42, 0:51).

## Motion and transitions
UI cards slide up from below and settle; a white bar sweeping across a blank frame bridges sections (cut at 22.4 s, frame 0:25). The purple rails stay put across every scene, so the background carries the film while the UI changes. Envelope flight is a playful bridge into onboarding. Ease is crisp ease-out, cards land in about 0.4 s.

## Pacing
Fast for a silent film: a caption or UI change every 2–3 s, real UI holds 3–6 s. Because there is no voice, the viewer reads constantly; the typed captions with marker chips do the narration's job.

## Sound
No voiceover. A light, upbeat electronic/pop bed around 99 BPM, mastered quiet. The high event count (142/min) points to many small ticks and pops on typing, chips and card landings.

## What to take from it
- Typed caption with a caret, then a marker chip snapping behind the keyword (0:10–0:13).
- Cursor presses Apply in a real filter panel, then the result card slides in (0:19–0:22).
- Stacking chips that list features while the UI beside them changes (0:31–0:34).
- Persistent background rails that carry every scene (whole film).

## Avoid
- Agency badge in the top-left corner on every frame: a corner label.
- No voice: dense captions are slower to absorb than a narrated line.
- Yellow ring pulse before the logo (1:03) is generic.
