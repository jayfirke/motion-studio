## Visual style
- Flat 2D vector "corporate illustration": long-limbed characters, no outlines.
- Royal blue primary, mustard secondary, a light cool-grey stage. Redrawn UI as white cards with thin type.
- Depth comes only from drop shadows and dimming layers behind popovers.

## How the product UI is shown (the demo grammar)
- Redrawn UI, faithful in structure (editor toolbar, metric tiles, widget config), floating on grey. A browser chrome appears only for the changelog (0:52).
- A white arrow cursor clicks pill-shaped primary buttons (0:31, 1:21, 1:38).
- **Macro zoom:** push into the bell (0:40), then pull back to reveal the popover over the dimmed dashboard (0:44). Close-up, then context.
- A floating URL pill above the browser says "your own domain" without a caption (0:52).
- Segmentation as one state change: filters set, and non-matching avatars lose their colour (1:17 → 1:21).

## Motion and transitions
- After 0:10.6 there is no detected cut for 76 s. Every UI beat morphs, slides or zooms on the shared grey stage, so it reads as one camera.
- Only three hard cuts, all in the character story and the closing split (5.1, 10.6, 87.1 s).
- Transitions are camera-driven: push into an icon, pull back to the parent, slide a page sideways (1:01). Characters bounce; UI moves cleaner and quicker.

## Pacing
- Medium: about 4 s per UI beat from 0:31 to 1:26.
- The 23 s character intro before the product is slow for the owner.

## Sound

## What to take from it
- **Macro push into an icon, then pull back to the panel it opens** (0:40 → 0:44). Clean cause, then result.
- **One neutral stage for 76 s** (0:10–1:27). Features chain without cuts, like a single take.
- **One message landing on four channels at once** (1:09). Reach proved in one frame.
- **A filter that greys out the non-matches** (1:17–1:21). Segmentation in one state change.

## Avoid
- A 23 s character skit before the product (0:00–0:23). Generic flat people read as dated.
- An icon burst around the megaphone (0:19). Decorative clutter.
- A centred logo on a plain field (0:27, 1:38).
