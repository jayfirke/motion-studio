## Visual style

Thin, light geometric sans; titles in a big/small pair (dark word over a lighter, smaller word). Oversized ghost words in pale blue sit behind the foreground as texture. Very airy, few elements per frame.

## How the product UI is shown (the demo grammar)
- Redrawn but faithful UI: prompt bar, plan table, slide editor, chat panel, all floating without device frames.
- Prompt first: the film opens on the input the user types, then shows the output, the clearest cause-and-effect order for an AI product.
- Arrow cursor clicks Ask (0:02) and clicks into an Insights box (0:18) to show the slides are editable.
- Split layout for chat: feature label left, live chat panel right, label swaps on each answer (0:39–0:49).

## Motion and transitions
No detected cuts: everything carries. The prompt pill moves into the node diagram; slides slide within one editor; framed clips shrink and slide aside for chat bubbles. Type assembles letter by letter (0:25, 1:06, 1:12) with blur-to-sharp. Easing is soft ease-in-out, slow-ish; nothing overshoots.

## Pacing
VO at 101 words/min in clipped two- and three-word fragments, each fragment owning one UI state, roughly one new state every 3.4 s. Breathes on "done in minutes" and "The result?", which hold about 3 s each.

## Sound

## What to take from it
- 0:00–0:08: open on the prompt itself, cursor clicks Ask, then the output. The best hook pattern for an AI tool.
- 0:05: the prompt becomes the hub of a small diagram showing the three things the AI reads; explains the brain in 3 s.
- 0:39–0:49: label-left, live-chat-right split; the label changes on each answer while the panel keeps filling. One layout, four features.
- 1:02–1:09: "The result?" then one huge word, then one metric pill: a clean proof beat.
- Ghost oversized words behind the UI as texture, keeping frames rich without extra cards.

## Avoid
- Stock executive footage in rounded frames (0:29–0:35): generic and breaks the UI world.
- Letter-by-letter fade-ins (0:25, 1:12): essentially opacity fades; use a mask or slide instead.
- Five circles with a tracing stroke (0:55): process-diagram filler.
- 101 words/min with long gaps between fragments is calmer than the owner wants.
