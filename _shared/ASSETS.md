# Asset licence ledger

Every non-generated file in `_shared/` (and anything a project brings in) needs a row here **before** it is used. `motion-asset-check` audits against this file. Licence texts live in `_shared/LICENSES/`. "Redist." means the files may be re-hosted (bundled in this folder or published in a web page).

Allowed: CC0-1.0, MIT, ISC, Apache-2.0, OFL-1.1, Unlicense, code-generated output, and Fish Audio `s2.1-pro-free` voice output. CC-BY-4.0 is allowed with a credit line. Mixkit files are allowed inside rendered videos only (no redistribution). Everything else is refused.
